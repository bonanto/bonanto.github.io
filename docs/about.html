Software, made for the love of it.

I'm Bonanto, an independent developer. Building software is my hobby, and this site is where I share what comes out of it.

How it started

I have been making Bengali keyboard tools since 2008. Rabiraag, my Bengali keyboard layout for Windows, has been tested across every Windows version from XP to 11. Since then I have built whatever I found interesting, or wished already existed.

Things I've made so far

A few of the areas I have worked in. The list keeps growing, because I follow my curiosity and new ideas turn into projects.

Typing and exams

Practice and evaluation software built around real exam rules, such as SM Type Test.

Keyboards and input

Bengali layouts and input methods for Windows and Linux, including Rabiraag and Saswati.

Utilities

Small tools that do one job well, like Bark, which keeps your system sound volume where you set it.

How I work

  • Native desktop apps, not wrapped web pages.
  • Plain statements about data. Each app page says whether it works offline, needs an account, collects usage data or shows ads.
  • Clear terms. Every app says whether it is free or paid, and open or closed source.

Working together
